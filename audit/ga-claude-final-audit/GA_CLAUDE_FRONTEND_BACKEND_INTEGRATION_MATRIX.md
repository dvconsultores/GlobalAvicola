- Columnas exigidas por el encargo (§7): identificación (proceso, BU, rol, ruta, página, entrada visible, acción, handler, servicio, método, endpoint, servicio backend), contratos (petición, respuesta), persistencia y auditoría, refresco de estado, permiso y alcance (empresa · BU de empresa · BU de usuario), desktop / móvil / ES / EN, manejo de errores, test automatizado, runtime E2E, UAT del propietario, veredicto, ¿bloquea?, brecha. Se agrupan en dos tablas por sección (A: identidad; B: contratos y estado) unidas por el ID.
- Fuentes: informes A (traza), B (contratos de petición, `B-nn`), C (respuesta / errores / estado, `C#n`), D (seguridad, `GAP-nn`), F (`G-nn`) de esta auditoría; matrices históricas DeepSeek (`audit/final-frontend-audit/`); código en HEAD; evidencia runtime en `audit/ga-claude-final-audit/evidence/` — recorrido real en `avicola.globaldv.net` (**[RT]**, `runtime_gp_e2e.log`) y pila local aislada (**[LOC]**, `ui_e2e_local.log`).
- Abreviaturas: `OFP` = `frontend/src/pages/operations/OperationFormPage.tsx` · `ODP` = `OperationDetailPage.tsx` · `LDP` = `LotDetailPage.tsx` · `MLP` = `MasterListPage.tsx` · `V` = `backend/app/operations/validators.py` · `S` = `backend/app/operations/schemas.py` · `SVC` = `backend/app/operations/service.py`.
- **Veredicto de paridad** (uno por fila): `FULL_PARITY` · `REQUEST_GAP` · `RESPONSE_GAP` · `PERSISTENCE_GAP` · `STATE_REFRESH_GAP` · `DEAD_ACTION` · `ORPHAN` (backend sin UI, o frontend sin backend; se indica cuál). Una fila `FULL_PARITY` puede arrastrar una brecha **solo** de manejo de errores; se anota en la columna de errores y se cuenta aparte.
- **¿Bloquea?** = `Sí` cuando impide completar o verificar por UI un proceso pre-SAP requerido, o desinforma en una pantalla crítica; `No`; `UNKNOWN`.
- **Alcance** = `empresa · BU empresa · BU usuario` según la cadena canónica (`tenancy.py` → `company_business_units.is_enabled` → `user_business_units` → RBAC; informe D §0). `—` = no aplica (plano de control / CORE).
- **Runtime E2E**: `E2E` (ejercitada por esta auditoría con el resultado indicado), `HIST` (evidencia L4/L5 DeepSeek reutilizada), `—` (no ejercitada), `BROKEN`.
