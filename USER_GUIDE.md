# 📖 Guía de Uso - Nuevo Diseño de Operaciones

## Para Operadores de Campo (Usuarios Móviles)

### 🏠 Dashboard Inicial

Al abrir la aplicación, verás:

1. **Encabezado Personalizado**
   - Saludo con tu nombre
   - Icono de brillo (✨)
   - Fondo azul gradiente

2. **Métricas de Hoy (KPIs)**
   - Operaciones registradas
   - Operaciones que requieren revisión
   - Operaciones aprobadas

3. **Alerta (si aplica)**
   - Se muestra solo si tienes correcciones pendientes
   - En color ámbar para llamar atención

### ⚡ Acciones Rápidas

Acceso rápido a las 4 operaciones más frecuentes:

- **🌾 Alimento** (Amarillo): Registrar consumo
- **⚖️ Pesaje** (Azul): Registrar peso
- **💀 Mortalidad** (Rojo): Registrar muertes
- **🥚 Huevos** (Naranja): Recolectar/clasificar

---

## 🎯 Cómo Registrar una Operación

### Opción 1: Usando Acciones Rápidas (⚡ Más Rápido)

1. Toca una de las 4 acciones rápidas
2. Llena el formulario
3. ✓ Listo

*Ideal para operaciones diarias comunes*

### Opción 2: Usando Procesos Principales (📋 Completo)

1. **Toca un proceso** (ej: "Progenitoras — Cría")
   - Verás el flujo completo de 10 etapas

2. **Selecciona un lote** (opcional)
   - Si trabajas con múltiples lotes, selecciona uno
   - Si dejas en blanco, lo seleccionas al registrar

3. **Expande una etapa** (clic en el número o el nombre)
   - Verás detalles y descripción
   - Aparece botón "Registrar operación"

4. **Toca "Registrar operación →"**
   - Se abre el formulario
   - El tipo de operación ya está seleccionado

5. **Llena los datos y guarda**
   - ✓ Operación registrada

## 📊 Entendiendo el Timeline

### Estados Visuales

**✓ Completado** (Verde)
- Ya registraste esta operación
- Se muestra con fondo verde
- Número en círculo verde

**→ En Progreso** (Azul)
- Estás trabajando en esta etapa
- Se muestra con fondo azul
- Número escala un poco más grande
- Badge azul indica "En progreso"

**○ Pendiente** (Gris)
- Aún no realizas esta operación
- Fondo gris claro
- Número en círculo gris

### Barra de Progreso

En cada proceso verás:
- Porcentaje completado (0-100%)
- Barra visual que se llena
- Ejemplo: "0 de 10 etapas completadas"

## 🔄 Flujo Típico de Trabajo

**Mañana - Progenitoras:**
1. Toca "Progenitoras — Cría"
2. Toca el lote (ej: "GP-001")
3. Expande "Inspeccionar granja"
4. Registra la inspección
5. Continúa con siguiente etapa...

**Tarde - Registros diarios:**
1. Usa acción rápida "Alimento"
2. Ingresa cantidad
3. Usa acción rápida "Pesaje"
4. Ingresa peso
5. Usa acción rápida "Mortalidad"
6. Ingresa número de muertes

**Final de jornada:**
1. Toca "Ver todas las operaciones" en dashboard
2. Revisa tu historial de hoy
3. Busca cualquier operación pendiente

## ❓ Preguntas Frecuentes

**P: ¿Qué pasa si cierro sin terminar?**
R: La operación se guarda como "borrador". Puedes completarla después desde el historial.

**P: ¿Puedo cambiar una operación registrada?**
R: Sí, desde el historial → toca la operación → "Editar"

**P: ¿Qué significa el color diferente en cada proceso?**
R: Cada proceso tiene un color único para identificarlo rápidamente en toda la app.

**P: ¿El lote es obligatorio?**
R: No, es opcional. Si no lo seleccionas, lo haces al registrar.

**P: ¿Puedo ver solo un proceso?**
R: Sí, toca uno cualquiera y verás su flujo completo sin distracciones.

**P: ¿Cómo sé qué operación hacer después?**
R: El orden es vertical de arriba a abajo. Sigue la secuencia numerada.

## 📱 Consejos para Móvil

✅ **Buen uso del espacio**
- Los botones son grandes para dedos
- Las cards se expanden/contraen
- Todo cabe sin scrollear demasiado

✅ **Colores vibrantes**
- Fácil de ver en luz solar
- Diferencia clara entre opciones

✅ **Acceso rápido**
- Dashboard → Acción en 2 toques
- Proceso → Operación en 3 toques

✅ **Progreso visual**
- Siempre sabes dónde estás
- Barra muestra avance
